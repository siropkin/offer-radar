# offer-radar

A public log of every recruiter pitch I've received (Jul 2026 → …) and politely
declined — cadence, company fields, and advertised salary ranges. Recruiters
are anonymized on purpose; channel only, no names, no emails.

**Live:** https://siropkin.github.io/offer-radar/

Single-file site: all data lives in the `DATA` array in `index.html`; every
chart, stat, and table recomputes from it. See `AGENTS.md` for the update
workflow and design rules.
